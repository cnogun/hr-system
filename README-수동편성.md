# 근무 스케줄 수동 편성 적용 안내

## 포함된 변경

- 1팀 구성 기준: 조장 4명, 일반경비 24명, 특수경비 10명 = 총 38명
- 직원 역할을 조장/일반경비/특수경비로 직접 지정
- 일반 편성은 A/B조와 1~4조를 직접 지정
- 특수경비는 특수 1~5조를 직접 지정
- 특수경비 지원조는 숨겨진 일반 1~4조 값이 아니라 특수 1~5조 값을 기준으로 선발
- 특수 1~4조는 각 2명씩 일요일 지원조 순환에 사용하고, 특수 5조는 토요일 기본 명단에 포함
- 날짜·근무대·팀별 조장/일반/특수 수동 선택
- 자동 생성·자동 순환·근태 자동입력 제거
- 수동 확정값 잠금 및 근무명령서 원본 데이터 저장
- 변경 사유, 수정 관리자, 수정 시각 저장
- 화면 글자·카드·입력칸을 축소한 밀도 높은 UI
- 사번/이름 검색 및 역할별 직원 필터
- 팀별 38명을 조장 4명, 일반경비 24명, 특수경비 10명으로 빠르게 입력하는 버튼
- 수동 편성 목록에는 지정된 역할의 직원만 표시
- 별도 주말 명단 입력 화면은 숨기고, 주말 근무 인원 요약은 기본 편성의 A/B조·1~4조에서 자동 계산
- 기본 편성 저장 직후 서버 값을 다시 조회해 실제 저장 결과 검증
- 날짜·근무대·팀 선택 시 기본편성을 바탕으로 근무명단 자동 표시
- 조장 순번 입력 없이 사번순 조장1~4를 판단
- 조장1은 토요일 근무에 포함하고 일요일 지원근무에서는 제외
- 일요일 지원조장은 조장2→조장3→조장4 순환하며, 해당 조장만 전날 토요일 명단에서 제외
- 선택조 자동 명단은 조장 1명, 일반 6명, 특수 2명으로 총 9명 구성
- 저장된 1~4조 인원수가 6/2와 다르면 해당 조 직원을 우선한 뒤 같은 역할의 다른 직원으로 보충하여 항상 일반 6명·특수 2명으로 구성
- 토요일 명단은 전체 38명에서 다음 날 지원조 9명을 제외하여 조장 3명, 일반 18명, 특수 8명으로 총 29명 구성
- 일요일은 주간팀 A/B조 19명과 지원조 9명을 합쳐 주간·야간 각각 28명 구성
- 일요일 화면에서 주간팀 19명과 지원팀 9명을 구분하고, 선택한 팀의 현재 명단 유형과 전체 28명 구성을 함께 표시
- 주간팀 일요일 조장은 주간 조장1·2/야간 조장3·4로 시작하고, 3주 뒤 다시 주간팀이 되면 서로 교대
- 상단 메뉴를 근무명단·기본편성 관리·법정공휴일 관리로 분리
- 평일 팀 스케줄과 주말 근무 인원 요약을 하나의 현황 카드로 통합
- 자동 명단에서 결원·휴가·대체근무 등 예외만 수정한 뒤 근무명단 확정
- 확정 후 전체 인원을 조장·일반·특수 구분, 사번, 이름, 기본조와 함께 접이식 표로 표시
- 전체 확정 인원수, 변경 사유와 확정 시각 표시
- 확정명단 다시 설정 및 기본 명단 재적용 후 기존 확정명단 교체
- 공휴일을 주차 스케줄과 분리된 Holiday 컬렉션에서 전체 기간 관리
- 기존 주차 스케줄에 저장된 공휴일 자동 이전, 같은 날짜 중복 등록 방지
- 공휴일 추가·조회·삭제 주소 통일, 저장 중 중복 요청 차단, 세션 만료 시 로그인 안내
- 등록 공휴일을 실제 자동 근무 스케줄의 공휴일 판정에 반영
- 전체 확정 근무명단을 날짜·근무대·팀·인원·변경사유·확정시각 목록으로 표시
- 목록에서 확정명단을 다시 불러올 수 있고 날짜와 관계없이 관리자 확인 후 삭제 가능

## 파일 위치

압축 파일의 파일을 기존 프로젝트의 다음 위치에 덮어씁니다.

- `Employee.js` → `models/Employee.js`
- `WorkSchedule.js` → `models/WorkSchedule.js`
- `workSchedule.js` → `routes/workSchedule.js`
- `workScheduleService.js` → `services/workScheduleService.js`
- `workSchedule.ejs` → `views/workSchedule.ejs`
- 나머지 파일은 기존 위치와 동일하게 유지합니다.

## 먼저 할 일

근무 스케줄 화면의 `직원 기본 편성 관리`에서 역할, A/B조, 1~4조, 특수 1~5조를 지정합니다. 기존 직원 데이터는 삭제되거나 자동 변경되지 않습니다.

## 확인 항목

1. 관리자 로그인 후 근무 스케줄 관리로 이동합니다.
2. 직원 기본 편성에서 `4/24/10 역할 배정`을 누릅니다. 38명을 초과한 직원은 삭제하지 않고 미편성으로 남습니다.
3. 사번 순 배정 결과와 특수 1~5조를 확인한 후 `기본 편성 저장`을 누릅니다.
4. 일자별 근무명단에서 날짜, 주간/야간, 팀을 선택합니다.
5. 자동으로 표시된 명단을 확인하고, 변수가 있는 경우에만 직원을 변경합니다.
6. 변경했다면 사유를 입력하고 `근무명단 확정`을 누릅니다.

운영상 인원 변동은 허용하지만 한 직원을 조장·일반·특수에 중복 선택할 수는 없습니다.
